## 🚩 규칙

### 스터디는 주 3문제로 시작하며, 진행 상황에 따라 문제 수를 점차 늘려갑니다.
- 처음부터 많은 문제를 풀기보다, 부담 없이 시작해 꾸준히 문제를 푸는 습관을 만드는 것을 목표로 합니다. 문제 풀이에 익숙해지면 문제 난이도를 점차 늘려가겠습니다.
- 3문제 외에 추가로 문제를 풀어도 좋습니다.

### 소스코드와 함께 **문제를 해결한 과정을 정리한 글**을 제출합니다.
- 정리본 작성 방식은 자유입니다.
- 사용한 알고리즘이나 자료구조, 해당 방법을 선택한 이유, 문제에 접근한 과정, 막혔던 부분과 해결 방법 등을 작성합니다.
- 문제를 어떤 흐름으로 분석하고 해결했는지 자신의 생각을 정리하는 것을 목표로 합니다.

발표 방식 대신 정리본 작성을 선택한 이유는, 자신이 발표하지 않는 문제는 풀이만 확인하고 넘어가기 쉽기 때문입니다. 또한 풀이 과정을 충분히 이해하지 않으면 문제가 조금만 변형되어도 해결하기 어려울 수 있습니다.

따라서 매주 문제를 풀며 생각의 흐름을 차근차근 기록하고, 비슷한 유형이나 변형 문제에도 적용할 수 있는 문제 해결 능력을 키우는 것을 목표로 합니다.

## ✅ 참여 방법

1. 이 저장소를 **fork** 한다.
2. fork한 저장소에 **본인 이름 폴더**를 생성한다.  
   - ⚠️ 폴더명에 `:`(콜론) 사용 금지
3. 자신의 풀이 소스코드와 풀이 과정 기록 md를 해당 폴더에 업로드한다.
4. commit 규칙을 지켜서 원본 저장소에 **Pull Request(PR)** 한다.  
5. ⚠️ 기존 폴더 삭제 금지! **개인 폴더 내부만 수정**

<br/>

```bash

- Time: {time}

```
- 그리고 문제 풀고 submit 누르면 자동으로 커밋이 완료됩니다. (초록색 체크가 활성화되면 성공!)
